# 小米笔记 · 本地版

一款灵感记录工具，模仿小米笔记的操作逻辑、动画和 UI 设计。

## 特性

- 📝 **快速记录** — 点击 + 按钮即可开始记录灵感
- 🎨 **多彩笔记** — 8 种颜色主题，让笔记更生动
- 📂 **分类管理** — 自定义分类，轻松整理笔记
- 🔍 **快速搜索** — 关键词高亮，秒速找到目标笔记
- 📌 **置顶功能** — 重要内容一键置顶
- 🗑️ **回收站** — 误删可恢复，安全无忧
- 🌙 **深色模式** — 护眼深色，夜间使用更舒适
- 💾 **本地存储** — 数据仅存设备，无需登录账号
- 📱 **移动优化** — 专为手机设计，流畅触控体验

## 技术栈

- React 18 + TypeScript
- Vite 构建
- Tailwind CSS
- Capacitor (Android)
- IndexedDB 本地存储

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 产品定位

灵感记录工具，方便快速捕捉灵感，数据存储在用户手机上，无需云同步。
